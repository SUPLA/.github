# Legacy and archived repositories

The SUPLA organization contains repositories that remain public for historical, compatibility, or migration reasons.

## Current guidance

### `supla-arduino`

Status: **archived**

Purpose today:
- historical reference,
- redirect point for older links and forks.

Rule:
- do not direct new contributors here,
- do not open new feature work here,
- route users to `supla-device`.

### `supla-espressif-esp`

Status: **legacy**

Purpose today:
- older ESP8266 / ESP8285 source tree.

Rule:
- use only when that legacy implementation is specifically required,
- do not present it as the default device-development entry point.

### `ESP8266`

Status: **legacy / redirect**

Purpose today:
- repository-level landing page for old ESP8266 firmware collection.

Rule:
- treat it as a redirect / compatibility layer,
- point new work to the relevant active or legacy source repository.
